# Third-party components

The application uses PySide6 Essentials/Qt 6 (LGPLv3/GPL/commercial options), Pillow (HPND), MSS (MIT), HTTPX (BSD), keyring (MIT), RapidOCR (Apache 2.0), ONNX Runtime (MIT) and their transitive dependencies. The build copies installed distribution license/notice files into `THIRD_PARTY_NOTICES` and emits a CycloneDX build-environment inventory including tooling. Consult those exact files for applicable terms, not this abbreviated overview.

Qt shared libraries remain separate in the folder distribution, allowing replacement with compatible modified libraries. Application source and build instructions are public. Users may reverse engineer the combined work as needed to debug modifications to LGPL components. PyInstaller's bootloader exception applies to its build output; its own notices are retained.

The release includes `DeskTranslate-2.0.0b1-LibrarySources.zip`: unmodified QtBase, QtSvg and PySide/Shiboken sources at the matching v6.12.0 tags, with SHA-256 values in `packaging/library-sources.json`. Obtain this alongside the installer/portable ZIP from the same release page. Original library license texts are included in the application notices. Follow the source archives' build instructions to produce compatible shared libraries and replace the matching files under `_internal/PySide6` or `_internal/shiboken6`; DeskTranslate does not enforce signatures or prevent replacement. This follows the [Qt LGPL redistribution requirements](https://www.qt.io/development/open-source-lgpl-obligations).

Recognition weights are the [RapidAI/RapidOCR](https://github.com/RapidAI/RapidOCR) distribution of PaddleOCR-family models. Exact pinned URLs and SHA-256 values are in `assets/models.json`. [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) uses Apache 2.0. Models are downloaded on explicit installation, verified and kept in application data; no model license is relabeled MIT. Maintain upstream attribution with any redistributed model files.

UI icons are repository-native SVG. Synthetic fixture images are authored for this project and rasterized with installed OS fonts; font programs themselves are not redistributed. No game/video captures or private text are bundled.
