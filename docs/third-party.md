# Third-party components

The application uses PySide6 Essentials/Qt 6 (LGPLv3/GPL/commercial options), Pillow (HPND), MSS (MIT), HTTPX (BSD), keyring (MIT), RapidOCR (Apache 2.0), ONNX Runtime (MIT) and their transitive dependencies. The build copies shipped distribution license/notice files into `THIRD_PARTY_NOTICES` and emits separate CycloneDX inventories for shipped Python distributions and the complete build environment. Runtime ownership is derived from PyInstaller's analysis inputs; native library licenses and Python's standard library need their own attribution, so this inventory is not an exhaustive native dependency graph. Consult those exact files for applicable terms, not this abbreviated overview.

Qt shared libraries remain separate in the folder distribution, allowing replacement with compatible modified libraries. Application source and build instructions are public. Users may reverse engineer the combined work as needed to debug modifications to LGPL components. PyInstaller's bootloader exception applies to its build output; its own notices are retained.

The release includes `DeskTranslate-2.0.0b2-LibrarySources.zip`: unmodified QtBase, QtSvg and PySide/Shiboken sources at the matching v6.12.0 tags, with SHA-256 values in `packaging/library-sources.json`. Obtain this alongside the installer/portable ZIP from the same release page. Original library license texts are included in the application notices. Follow the source archives' build instructions to produce compatible shared libraries and replace the matching files under `_internal/PySide6` or `_internal/shiboken6`; DeskTranslate does not enforce signatures or prevent replacement. This follows the [Qt LGPL redistribution requirements](https://www.qt.io/development/open-source-lgpl-obligations).

Recognition weights are the [RapidAI/RapidOCR](https://github.com/RapidAI/RapidOCR) distribution of PaddleOCR-family models. Exact pinned URLs and SHA-256 values are in `assets/models.json`. [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) uses Apache 2.0. Models are downloaded on explicit installation, verified and kept in application data; no model license is relabeled MIT. Maintain upstream attribution with any redistributed model files.

UI icons are repository-native SVG. Synthetic fixture images are authored for this project and rasterized with installed OS fonts; font programs themselves are not redistributed. No game/video captures or private text are bundled.

Release CI uses the hash-pinned CPython 3.12.15 Windows x64 distribution from [Python Build Standalone](https://github.com/astral-sh/python-build-standalone/releases/tag/20261009), because official Python 3.12 Windows installers ended at 3.12.10. CPython and its OpenSSL runtime appear separately in both inventories and build provenance; their original notices, and native runtime license texts from that pinned source tag, are retained under `THIRD_PARTY_NOTICES/Library-source-licenses/python`. The runtime inventory remains a distribution inventory with those two explicit native components, not an exhaustive graph of every embedded native dependency. The archive SHA-256 and preparation steps are fixed in `tools/install_python.ps1`.
