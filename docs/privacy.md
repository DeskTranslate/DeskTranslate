# Privacy

DeskTranslate captures the fixed region, monitor or application client region you explicitly choose during a translation session. Application capture checks executable identity, window identity, visibility and geometry before and after reading pixels; missing, covered or minimized targets never fall back to another application. Selection previews are frozen screen images held in memory and released when selection ends. OCR pixels, recognized text, translations, bounded context and cache remain in memory. Explicit developer preview/benchmark commands create authored synthetic artifacts.

The Session page's transcript is off by default. If enabled, it retains at most 200 entries/100,000 characters in memory, supports search/copy, and clears on Stop or setup/session changes. Export requires an exact-content preview and a file you choose. There is no automatic transcript file, crash recovery or persistent history. Your latest result remains visible until another result replaces it or the app closes.

OCR is local. Contextual AI translation sends recognized text, language choices, relevant approved glossary terms, configured story notes/style instructions and bounded recent dialogue to the selected provider. Conventional translation sends the current text and language choices; an exact whole-term glossary match is resolved locally. Screenshots are never sent. Local Ollama/LM Studio or compatible loopback services receive this data on the machine; their own configuration determines downstream behavior and prompt logging. A local server may retain prompts/text in its own files even though DeskTranslate does not log them; configure that server independently. No automatic cloud fallback occurs. Your provider's retention policies apply independently of DeskTranslate.

Keys are bound to provider and endpoint identity in OS credential storage, not settings. Unsupported or plaintext keyring backends fail closed. Remote HTTP is rejected, HTTPS certificate verification remains enabled, and provider redirects are rejected. Remote services may honor system/environment proxy configuration; loopback providers bypass those proxies. Native OpenAI Responses and native Chat Completions requests set `store: false`; other providers retain their own policies. No adapter silently changes to a cloud provider.

Settings, model files and metadata-only rotating logs use `%LOCALAPPDATA%\DeskTranslate` for the Windows installer, or adjacent `DeskTranslateData` when the portable marker is present. Settings include your glossary and its language pair, explicit story notes, instructions, provider/model/endpoint, profiles and locally selected capture target. These are user-authored configuration, not inferred history. Story notes are optional and limited to2,000 characters. Loading a legacy profile without semantic configuration clears the previous title's notes, terms and instructions. Deleting the active profile clears those values from the current setup as well. Window identity includes executable basename, a path hash and title; titles may contain a document name. Treat these files as private. Profile export excludes capture identity and coordinates by default and always excludes keys. Its preview includes story notes, glossary, instructions and configured endpoints, which you should review before sharing. Imports require a fresh local capture selection.

Logs discard messages, dialogue, URL paths, headers, API keys and exception tracebacks. Diagnostics previews and exports use a separate metadata allowlist: versions/build, OS/architecture, display layout, model integrity identifiers, numeric resource/counter/latency data and error categories. They exclude usernames, private paths, endpoints, prompts, screen text and keys. Translation model ID is excluded unless you explicitly include it. Export only the JSON shown in the preview; no raw log archive is silently attached.

A local ownership lock prevents two launches from overwriting the same preferences. Qt's lock contains process/machine ownership metadata and is removed on clean exit; a crash can leave it for stale-owner recovery. The Windows activation pipe is restricted to the same user and carries only a fixed restore-window request/reply, never screenshots, text, credentials or file paths. Automated verification does not activate an existing window.

DeskTranslate has no app analytics and no periodic update request. It sets ONNX Runtime's process-local opt-out before native import and calls its telemetry-disable API before inference sessions. The pinned upstream [privacy policy](https://github.com/microsoft/onnxruntime/blob/v1.30.0/docs/Privacy.md) distinguishes non-Windows runtime opt-out from Windows ETW and notes that a minimal initialization event can precede API suppression under an external trace session. OS diagnostics are outside this app's control; a zero-event ETW/packet trace has not been qualified.

Recognition installation fetches pinned model files only when you click Install. Find local servers sends discovery requests to loopback. Test connection sends a synthetic greeting for conventional MT, or requests the model catalog for AI. Guided setup translates an authored bundled sample only when you press its test button. Check for updates explicitly requests GitHub release metadata for your selected stable/beta channel. Opening verified release notes is a separate click. No executable is downloaded or run by the updater.

Clipboard copy is explicit; other applications or clipboard-history services may retain what you copy. Uninstall removes the program; settings/models remain for reinstall. Delete `%LOCALAPPDATA%\DeskTranslate` for a clean local reset. Delete saved provider keys through Providers or Windows Credential Manager. DeskTranslate never backs up old configuration containing secret fields.

Release privacy checks include source/history signatures, extracted frozen modules, runtime files and checksum-listed downloads/ZIP members. Notices copy license text rather than Python source or bytecode caches. Three known upstream build-metadata inputs can be reported separately only after matching the installed hash-locked wheel RECORD; frozen NumPy configuration must also match its normalized compiled source. These exceptions never cover application code, credentials or private-key material. They distinguish public upstream toolchain metadata from local developer data; the scan does not prove absence of every possible secret.
