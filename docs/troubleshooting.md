# Recovery and FAQ

**Recognition is not installed.** Choose your source script, open Recognition and install its pack. Download progress includes verification. Retry after cancellation or a failed hash; partial files never become installed models. Japanese and Korean need their explicit packs. Auto is Chinese/Latin recognition, not a universal script detector. Keep original colors first; contrast/upscaling can help small subtitles but does not improve every image.

**The application capture is waiting.** Restore the exact chosen window and uncover its subtitle region. The visible-screen backend cannot read through another window, minimize, protected video or every exclusive-fullscreen game. Use windowed/borderless mode. If a game restarted, reselect its window; enable restart following only if you want unique identity/title reconnection. Ambiguous matches always wait. Movement/resize follows the normalized client crop and clears old dialogue context.

**The overlay has no safe space.** Select a tighter subtitle region or use one-shot mode. An entire screen/client crop may leave no place for the overlay without capturing itself; the main window can show a one-shot result. Edit mode restores mouse interaction and pauses live translation. Hide persists across new results; Show/Hide makes it visible again. Copy retains the full translation even if the line limit clips it.

**A network or model error pauses translation.** The overlay/status says what failed and how to recover; it does not open the main window over your game. Test the provider, replace an invalid key or select another model, then resume. OCR worker crashes have bounded local recovery; repeated failure pauses and asks you to adjust the region/engine. Sleep stops capture; start explicitly after wake. Fixed-region display changes require reselection; application targets are revalidated.

**Shortcuts do not work.** Check Preferences for the assigned shortcut and conflicts. First-run registration can add Shift or Win if another program owns a default. All eight actions are configurable. Closing exits by default; close-to-tray is opt-in. Use the tray menu or assigned overlay shortcut to regain controls while click-through is enabled.

**Can I use it completely offline?** After installing the required OCR pack, recognition is offline. Translation is offline only with an already installed/loaded local LLM or local translation service. DeskTranslate does not install large LLMs or switch you to a cloud provider when local setup fails.

**Does portable save beside the executable?** No. Keep the entire portable folder, including `_internal`, together. Settings/models/logs use `%LOCALAPPDATA%\DeskTranslate`; API keys use the OS vault. Reinstall/uninstall preserves your user data. Profiles and settings from beta1 are validated/migrated; beta1 OpenAI retains Chat mode. V1's executable-path configuration is not imported; use guided V2 setup. Unsupported Python installs are unnecessary for the Windows binary.

**How do I share a support report?** Diagnostics previews exactly what it will copy/export. It omits screenshots, dialogue, keys, endpoints and private paths; model ID is optional. Review profile/transcript/glossary exports separately because those may contain your terminology or text. Never attach your settings, OS credentials or private game/document captures to a public issue.

**Why is this still a beta?** Signing is unavailable and clean-machine, physical mixed-DPI/fullscreen, screen-reader, paid/local provider and prolonged media qualification remains incomplete. Automated and synthetic checks are documented, with their limits. Checksums are integrity checks, not publisher identity.
